# Google Sign-In Redirect URI Mismatch Fix

## Error Description
```
Access blocked: This app's request is invalid
Error 400: redirect_uri_mismatch
```

## Root Cause
The redirect URI generated by the Expo app doesn't match the authorized redirect URIs configured in Google Cloud Console for your OAuth 2.0 Client IDs.

## Current App Configuration

### App Scheme
- **Scheme**: `tics` (configured in `frontend/app.json`)
- **Bundle ID**: `com.kavumadennis.tics`
- **Package**: `com.kavumadennis.tics`

### OAuth Client IDs (from frontend/.env)
- **Web Client ID**: `956886937569-s0db9qdqbkrgvpid8tv6179h17260bi5.apps.googleusercontent.com`
- **iOS Client ID**: `956886937569-6gmg8ffsql5r4ppvupu9ommmqk89k9qo.apps.googleusercontent.com`
- **Android Client ID**: `956886937569-ksa8cldm1ootk02el858b63jmk50c6if.apps.googleusercontent.com`

## Solution: Add Redirect URIs to Google Cloud Console

### Step 1: Get the Exact Redirect URI

The app generates redirect URIs dynamically. To find the exact URI:

1. Run the app in development mode: `cd frontend && npx expo start`
2. Check the console logs for: `[Google Auth] Redirect URI: <your-redirect-uri>`
3. The URI will look like one of these:
   - **Development (Expo Go)**: `exp://127.0.0.1:8081/--/` or `exp://<your-ip>:8081/--/`
   - **Development Build**: `tics://redirect`
   - **Web**: `http://localhost:8081` or your production domain

### Step 2: Configure Google Cloud Console

1. Go to [Google Cloud Console](https://console.cloud.google.com/apis/credentials)
2. Select your project: **tics-455d5**
3. Navigate to **APIs & Services → Credentials**
4. Find and edit each OAuth 2.0 Client ID:

#### For Web Client ID (`956886937569-s0db9qdqbkrgvpid8tv6179h17260bi5.apps.googleusercontent.com`):
- **Authorized redirect URIs** - Add ALL of these:
  ```
  http://localhost:8081
  http://localhost:19006
  http://localhost:19000
  https://tics-455d5.firebaseapp.com/__/auth/handler
  ```
- **Authorized JavaScript origins** - Add:
  ```
  http://localhost:8081
  http://localhost:19006
  http://localhost:19000
  https://tics-455d5.firebaseapp.com
  ```

#### For iOS Client ID (`956886937569-6gmg8ffsql5r4ppvupu9ommmqk89k9qo.apps.googleusercontent.com`):
- **Authorized redirect URIs** - Add:
  ```
  tics://redirect
  com.kavumadennis.tics:/oauth2redirect
  ```
- **Bundle ID**: `com.kavumadennis.tics`

#### For Android Client ID (`956886937569-ksa8cldm1ootk02el858b63jmk50c6if.apps.googleusercontent.com`):
- **Authorized redirect URIs** - Add:
  ```
  tics://redirect
  com.kavumadennis.tics:/oauth2redirect
  ```
- **Package name**: `com.kavumadennis.tics`
- **SHA-1 certificate fingerprint**: Add your debug and release SHA-1 fingerprints

### Step 3: Get SHA-1 Fingerprints (for Android)

Run these commands to get your SHA-1 fingerprints:

```bash
# Debug SHA-1
cd android && ./gradlew signingReport

# Or using keytool
keytool -list -v -keystore ~/.android/debug.keystore -alias androiddebugkey -storepass android -keypass android
```

Add the SHA-1 fingerprints to the Android OAuth client in Google Cloud Console.

### Step 4: Enable Required APIs

Ensure these APIs are enabled in Google Cloud Console:
1. Go to **APIs & Services → Library**
2. Enable the following:
   - **Google Identity Services** (formerly Google Sign-In)
   - **Firebase Authentication API**

### Step 5: Restart and Test

1. Restart the Expo bundler: `cd frontend && npx expo start --clear`
2. Clear app cache if using a development build
3. Test Google Sign-In

## Alternative: Use Expo's Auth Session Proxy (Recommended for Development)

For easier development, you can use Expo's auth proxy which handles redirect URIs automatically:

1. In `frontend/src/screens/LoginScreen.tsx`, ensure you're using:
   ```typescript
   const [googleRequest, , promptGoogle] = Google.useAuthRequest({
     scopes: ['profile', 'email', 'openid'],
     redirectUri: AuthSession.makeRedirectUri({
       scheme: 'tics',
     }),
     clientId: process.env.EXPO_PUBLIC_GOOGLE_EXPO_CLIENT_ID || process.env.EXPO_PUBLIC_GOOGLE_WEB_CLIENT_ID,
     webClientId: process.env.EXPO_PUBLIC_GOOGLE_WEB_CLIENT_ID,
   });
   ```

2. Create an **Expo Go** OAuth client in Google Cloud Console:
   - Client type: **iOS** or **Android**
   - Package name: `host.exp.exponent`
   - Bundle ID: `host.exp.exponent`
   - Add redirect URI: `exp://127.0.0.1:8081/--/`

## Common Issues

### Issue: "redirect_uri_mismatch" persists
**Solution**: Double-check that the redirect URI in the error message exactly matches one in Google Cloud Console (including protocol, port, and path).

### Issue: Works in development but not in production
**Solution**: Add your production domain to authorized redirect URIs and JavaScript origins.

### Issue: Android sign-in fails
**Solution**: Ensure SHA-1 fingerprints are correctly added to the Android OAuth client.
